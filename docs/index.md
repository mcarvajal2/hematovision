# Conocimiento del proyecto

Este índice separa evidencia histórica, interpretación actual y trabajo futuro. Las etiquetas de certeza significan:

- **CONFIRMADO**: respaldado por artefactos inspeccionados o evidencia explícita.
- **INFERIDO**: conclusión razonable derivada de evidencia, pero no observada directamente.
- **HIPÓTESIS**: explicación posible que requiere verificación.
- **PENDIENTE**: pregunta abierta; no debe asumirse una respuesta.

## Regla de mantenimiento

La información estable no debe vivir únicamente en un chat. Al persistirla, actualiza el documento dueño y los enlaces o índices que hagan falta para mantenerla localizable. No dupliques contenido: enlaza a la fuente de verdad.
