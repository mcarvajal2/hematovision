# Contribuir a HematoVision

1. Crea una rama desde `main` con un nombre descriptivo: `feat/...`, `fix/...` o `docs/...`.
2. Mantén cada cambio pequeño y con una finalidad clara.
3. Ejecuta `npm run check` antes de abrir un pull request.
4. Describe en el pull request el impacto funcional, las pruebas y, si corresponde, el modelo/dataset utilizado.
5. No subas datos de pacientes, imágenes identificables, tokens, claves ni archivos `.env`.

Los cambios de modelo deben seguir el [protocolo de actualización](docs/update-protocol.md) y actualizar la ficha del modelo.
